# Data for the PRX Intelligence manuscript

Supporting material for **Learning Quantum Matter through Attention in Complex Space**.

- [22 November 2026 snapshot](2026-11-22/): the completed three-supercell benchmark,
  current optimizer and uniform-gas figure data, plotting sources, diagnostics,
  and manuscript artwork transferred from Overleaf. A per-file checksum manifest
  accompanies the snapshot.
- [Earlier supplemental package](supplemental-data.zip): earlier numerical inputs
  and supporting comparisons, including the Figure 3 density/Fourier data.
  The historical two-electron CI study in this package is not used in the current
  manuscript. The existing archive is retained unchanged.

See the snapshot README and the source-directory READMEs for file meanings,
uncertainty definitions, and figure-reproduction instructions. Raw Monte Carlo
configuration streams and trained checkpoints are retained separately by the authors.
